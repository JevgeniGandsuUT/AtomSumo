# Real CAD Package

This folder contains the real Fusion 360 CAD files for the robot mechanical package and related components.

## Main Assemblies

- [Robot.f3d](<Robot.f3d>) - robot-level Fusion design.
- [Assembly new.f3z](<Assembly new.f3z>) - packed Fusion assembly archive.
- [Rawproto.f3z](<Rawproto.f3z>) - raw prototype assembly archive.

## Robot Body Parts

- [Base 1.f3d](<Base 1.f3d>) - base body part.
- [Shell.f3d](<Shell.f3d>) - outer shell/body.
- [Topcover.f3d](<Topcover.f3d>) - top cover.
- [Battery pack.f3d](<Battery pack.f3d>) - battery pack/body integration.
- [PCB body.f3d](<PCB body.f3d>) - PCB body/holder geometry.
- [Floor.f3d](<Floor.f3d>) - arena or floor reference model.

## Drive and Hardware Parts

- [Wheel.f3d](<Wheel.f3d>) - wheel model.
- [wheel 43mm.f3d](<wheel 43mm.f3d>) - 43 mm wheel model.
- [Rear axcel.f3d](<Rear axcel.f3d>) - rear axle part.
- [N20 Reduction Gear Motor - LA002 LA003 LA004.f3d](<N20 Reduction Gear Motor - LA002 LA003 LA004.f3d>) - N20 motor model.
- [M5 ATOM Lite.f3d](<M5 ATOM Lite.f3d>) - M5 Atom controller model.

## Submission Note

For Verstapost 4 and 5 this folder should be treated as the strongest mechanical evidence, because it contains real Fusion 360 source files for the assembled robot, body, wheels, motor reference, battery packaging, PCB holder, and controller placement.
